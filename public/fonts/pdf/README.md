# PDF font assets

Noto Sans, copyright The Noto Project Authors, distributed under `OFL.txt`.
Source: https://github.com/google/fonts/tree/main/ofl/notosans

These are static instances of the upstream variable font at width 100, weights 400 and 600, generated with fontTools. Their PostScript names are distinct (`NotoSans-Regular` and `NotoSans-Semibold`); PDFKit requires distinct names to avoid font-cache collisions and incorrect glyph mappings. Keep these names distinct when updating fonts.
